# Guia de contribuição

## Primeiramente

Antes de enviar uma alteração para este repositório, se já não houver uma issue, crie uma a partir do template e use as labels para ajudar na identificação. Confira as políticas do projeto:

- [Código de conduta](CODE_OF_CONDUCT.md)
- [Como contribuir](https://fga-eps-mds.github.io/MeasureSoftGram-Docs/docs/como-contribuir/)
- [Política de commits](https://fga-eps-mds.github.io/MeasureSoftGram-Docs/docs/politica-de-commits/)
- [Política de branches](https://fga-eps-mds.github.io/MeasureSoftGram-Docs/docs/politica-de-branches/)
- Critérios de aceitação cumpridos
- Testes automatizados para tudo o que for alterado

## Crie uma branch ou um fork

Crie sua branch a partir de `develop`, ou faça um fork do repositório se você for um desenvolvedor externo.

## Rode a extensão e os testes

A seção "Desenvolvimento e release" do [README](README.md) traz os comandos para instalar as dependências da extensão e da interface (`webview-ui/`) e rodar os testes unitários e de integração.

## Crie o pull request

Abra o pull request no GitHub com a branch `develop` como base e a sua branch como comparação.

## Revisões

Se mudanças forem solicitadas, corrija-as e peça uma nova revisão.

**Muito obrigado por contribuir!**
